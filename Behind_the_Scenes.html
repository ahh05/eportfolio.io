#1 HTML Practice

For this project, I followed a LinkedIn Learning course to guide me through creating a digital project page for a terrarium. I started by learning HTML, which helped me structure the webpage and add headings, paragraphs, and images. Next, I learned CSS to style the page such as adding colours, rounded corners, spacing, and layout design to make it visually appealing. Finally, I explored basic JavaScript to add simple interactivity, such as hover effects and animations for the project images.

#2 CSS Practice

For this project, I followed a YouTube video tutorial to create a functional web calculator. While I applied HTML to build the structure and CSS for styling, the main focus of this project was learning JavaScript functionality. I used JavaScript to make the calculator interactive. Particularly handling number input, performing arithmetic operations, updating the display dynamically, and managing user interactions like clearing or deleting input.
